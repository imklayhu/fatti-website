# 跟练教程「从 0 到 1 用 AI 做出你的微信小程序」· 目录索引

> 配套写作规范：`docs/ops/tutorial/WRITING-GUIDE.md`
> 配套规划文档：`docs/ops/2026-08-12-build-along-tutorial-plan.md`

## 一、这是一本什么样的教程

手把手教你把一个小程序从 0 做到上线，全程使用 AI 编程工具（Cursor），以 FatTI「找到狡猾的猪腰」为真实案例。面向完全不懂开发的小白与尚未深度使用 AI 的开发者。

- 真实技术栈：前端 Taro + React + TypeScript + Sass，后端 FastAPI + PostgreSQL，部署 Nginx + Cloudflare + 腾讯云轻量服务器
- 真实节奏：2026-07-20 起步，08-12 发布 v1 正式版，约 3 周
- 教学承诺：第 5 到 9 章纯前端，零服务器、零域名、零花费即可跑通
- 成本承诺：最省方案首年约 500 到 1000 元（见 `appendix-b-budget.md`）

## 四、全文硬性约定

1. **截图占位符格式**：`![S01 · Cursor 官网下载页](tutorial-assets/S01.png)`，编号与上表严格一致
2. **隐私红线**：真实 AppID/AppSecret/公网 IP/域名/账号/密钥一律用占位符（`<你的AppID>`、`<你的域名>`、`example.com`、`1.2.3.4`、`wx1234567890abcdef`）
3. **零 em/en-dash**：全站禁用 em-dash（一长横）与 en-dash（一短横）这两类符号，用逗号/句号/括号替代
4. **章节结构**：目标引言 → X.0 引入 → 若干小节 → 自查清单 → 本章小结
